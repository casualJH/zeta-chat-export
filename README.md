# 제타 대화 내보내기 (TXT/JSON)

제타(Zeta) 채팅방의 과거 대화를 불러와 필요한 부분을 선택하고 **TXT 또는 JSON 파일로 저장**하는 Tampermonkey 유저스크립트입니다.

- 최신 버전: **v1.1.3**
- 사용 사이트: https://zeta-ai.io/
- 지원 방식: Tampermonkey 유저스크립트 (모바일 Safari 환경을 고려한 UI 제공)

## 설치

1. 브라우저에 **Tampermonkey**를 설치합니다.
2. [유저스크립트 설치 파일](https://raw.githubusercontent.com/casualJH/zeta-chat-export/main/zeta-chat-export.user.js)을 열어 설치합니다.
3. 제타 채팅방을 열고 **대화 저장** 버튼을 누릅니다.

기존 버전이 따로 설치되어 있다면 중복 실행을 피하도록 이전 스크립트를 비활성화해 주세요.

## 주요 기능

- **과거 대화 불러오기:** 텍스트 대화와 별도 `INFO_BOX` 상태창을 함께 수집합니다. 상태창이 없는 채팅방도 지원합니다.
- **대화 선택:** 최근 5·10·50·100개 누적 선택, 전체 선택·해제, 번호 범위 선택, 대화 카드 선택 및 화면 말풍선 직접 선택을 지원합니다.
- **수집/선택 개수 표시:** 개수를 별도의 숫자 카드로 표시하고 선택 결과를 실시간 반영합니다.
- **저장 시 제외 옵션:** `OOC:`가 포함된 메시지 전체, `요약`이 포함된 메시지 전체, 상태창, 일반 코드블록을 선택적으로 제외할 수 있습니다. 원본 제타 대화는 변경하지 않습니다.
- **TXT 저장 옵션:** 날짜/시간을 제거하거나 사용자 이름을 지정할 수 있습니다.
- **JSON 저장:** `index`, `time`, `role`, `speaker`, `text`를 유지하며, 상태창은 `role: "info_box"`, `type: "INFO_BOX"`로 구분합니다.
- **화면 설정:** 버튼과 창의 위치·크기를 조절하고 브라우저에 저장할 수 있습니다. 사용자 이름 미입력 시 입력창 테두리를 강조합니다.

## 사용 방법

1. 제타 채팅방에서 **대화 저장** → **과거 대화 불러오기**를 누릅니다.
2. 최근 개수, 전체/범위, 말풍선 또는 대화 카드 방식으로 저장할 대화를 선택합니다.
3. **저장 시 제외할 내용**을 설정하고, 필요하면 사용자 이름과 파일명을 입력합니다.
4. **TXT 저장** 또는 **JSON 저장**을 누릅니다.

> **주의:** 불러오기 중 네트워크 오류나 요청 제한이 발생하면 일부 대화만 수집될 수 있습니다. 저장 전에 수집 완료 상태를 확인해 주세요. 사이트의 변경이나 브라우저 환경에 따라 동작이 달라질 수 있습니다.
